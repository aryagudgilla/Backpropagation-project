How the network learns

Every training cycle follows the same fundamental process.

01

Forward propagation

Input values pass through the hidden layer and produce a prediction.

02

Calculate error

The prediction is compared with the expected target using the loss function.

03

Backpropagation

The error travels backward and determines how each weight contributed to the mistake.

04

Update weights

Gradient descent adjusts the weights so the next prediction becomes more accurate.
